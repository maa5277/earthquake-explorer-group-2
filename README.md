# Earthquake Explorer

MongoDB project for ISTE-438.
## Description

A web application that allows users to search and explore earthquake data using MongoDB.

## Features

- Keyword search
- Magnitude filtering
- Date filtering
- Geospatial search
- Earthquake details
- Comments
- GridFS image storage
