# Earthquake Explorer Project Plan

## Team Members
- Mohamed Ahmed
- Max Murray

## Dataset
Global Earthquake Dataset

## Features

### Search
- Search earthquakes by keyword
- Search by location
- Search by magnitude
- Search by date

### Geospatial
- Find earthquakes near a location
- Display coordinates on a map

### Details
- View detailed earthquake information

### Comments
- Users can add comments to earthquake records

### Images
- Store and retrieve images using MongoDB GridFS

## Collections

### earthquakes
Stores earthquake records and geographic coordinates.

### comments
Stores comments linked to earthquake records.

### images
Stores images using GridFS.

## Technology
- MongoDB
- Node.js
- Express
- HTML/CSS/JavaScript
